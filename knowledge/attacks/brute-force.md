# Brute Force

## Description
Repeated authentication attempts that may indicate credential guessing.

## Common Indicators
- Repeated failed authentication events
- Multiple login attempts
- Repeated attempts associated with a source indicator

## Typical Evidence / Logs
- Authentication logs
- Identity provider logs
- SIEM alerts
- Account activity records
